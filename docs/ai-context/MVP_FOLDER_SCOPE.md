# Bcentx Cursor MVP Folder Scope Guide

## Core Rule

For MVP, focus only on documents and work that support:

- Product direction
- App architecture
- Database design (after Sprint 1)
- UI / page structure
- Admin dashboard (after auth sprint)
- SEO structure
- Legal / disclosure rules
- Brand assets
- V1 theme preservation
- Git workflow and build tracking

Do **not** treat deep research prompts, raw research reports, AI system planning, monetization expansion, or archives as Sprint 1 build drivers.

## In-Repo MVP Docs

| Path | Purpose |
|---|---|
| `docs/ai-context/` | AI / developer command center |
| `docs/build-log/` | Session memory and decisions |
| `legacy/v1-static-site/` | Archived V1 prototype (reference only) |

Full Drive package folders (`00`–`16`) remain outside the repo except the condensed AI context copies here.

## Build Order (MVP)

1. Project setup ← Sprint 1
2. Theme / design system
3. Supabase schema
4. Auth / admin protection
5. Public layout
6. Category → opportunity → platform → country → risk pages
7. Roadmaps / blog / glossary
8. Admin dashboard
9. SEO / legal layer
10. Seed content
11. QA / launch prep

## Do Not Build First

AI chatbot, recommendation engine, paid subscriptions, community, mobile app, portfolio tracker, crypto wallet, investment execution, advanced affiliate dashboard, mass content generation from research reports.
